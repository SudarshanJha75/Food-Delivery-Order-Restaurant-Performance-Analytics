# Data sources and provenance

## Included dataset
- File: `dataset/raw/bengaluru_food_delivery_sample.csv`
- Type: Synthetic demonstration data generated with NumPy.
- Geography label: Bengaluru areas used as simulated categories.
- Records: 1,500.
- Date range: 2025-01-01 through 2025-06-29 (generated date range).
- Not collected from Swiggy, Zomato, restaurants, customers or delivery partners.
- Do not describe the records as actual Bengaluru orders.

## Replacing or supplementing with public data
Before using an external dataset, record:
1. Exact dataset title and publisher.
2. Direct download/source URL.
3. Licence and permitted uses.
4. Date accessed.
5. Original geography and time period.
6. Cleaning and filtering steps.

Never merge separate datasets as if they share order IDs unless a valid documented key exists.

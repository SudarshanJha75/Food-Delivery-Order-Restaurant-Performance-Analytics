# Project Abstract

The Food Delivery Order & Restaurant Performance Analytics project demonstrates an end-to-end data analytics workflow for studying food delivery operations in a Bengaluru case-study context. The system covers order trends, restaurant performance, customer and area patterns, revenue indicators, delivery efficiency and a basic delivery-time prediction workflow.

Python and Pandas are used for data preparation, exploratory analysis and feature processing. SQL examples demonstrate relational storage and analytical querying. A Scikit-learn regression pipeline demonstrates delivery-time prediction, while Streamlit and Plotly provide an interactive dashboard.

The starter package includes synthetic demonstration data. Therefore, the initial outputs are intended to demonstrate implementation and must not be interpreted as measured performance of a real food delivery platform. A future empirical version should use appropriately licensed and geographically documented real-world data.

**Keywords:** Food delivery analytics, Python, Pandas, SQL, machine learning, Streamlit, restaurant analytics, delivery time.
